하루 3.0-Q — AI 대화 오류 복구 시험판 (2026-11-20)

기준: 하루 3.0-P. 기존 데이터 저장 키와 겨울 홈 디자인 유지.

변경:
1. AI가 수정된 장소만 반환해도 대기 중인 일정의 제목/날짜/시간과 합침. AI가 의도를 결정하며 코드에 특정 표현을 사전 등록하지 않음.
2. AI 응답에서 선택 필드 생략 시 빈 문자열로 보완. 잘못된 날짜/시간은 저장하지 않음.
3. AI 요청 실패는 오류 코드로 구분하여 표시. 오류도 대화 화면에 표시하지만 다음 AI 요청의 대화 맥락에서는 제외.
4. 서버의 일시적 HTTP 429/5xx 또는 타임아웃에 한 번 재시도. 기존 등록 대기 정보는 보존.
5. 일정 목록 팝업 수정/삭제 버튼을 블루그레이로 정리.

검증: Node.js 문법 검사, 모의 서버 응답 시뮬레이션(제안→장소 부분수정→확인, 오류→정상 복구, 대화 기록 제외) 통과.
주의: 실제 Cloudflare AI 서버와 iPhone 실기기 테스트는 수행하지 못함. 기존 데이터 백업 권장.
