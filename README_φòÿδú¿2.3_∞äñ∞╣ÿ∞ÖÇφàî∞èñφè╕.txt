하루 2.3 통합 개인비서 시험판 (2026-11-17)

기준: Haru_2.2.1_AllInOne_Test.zip 원본 8개 파일을 유지하고 haru23.js 및 화면/스타일 확장.

추가된 기능
- 나의 일정: 목록 보기 / 캘린더 보기 전환
- 월간 달력: 일정 제목 표시, 날짜 선택, 상세 확인, 목록에서 수정
- 홈: 오늘 일정/미완료 할 일/다음 일정 요약
- 오늘 브리핑: 오늘·내일 일정과 남은 할 일 요약
- 대화: '오늘 일정 알려줘', '내일 일정 알려줘', '이번 주 일정 알려줘', '이번 달 병원 예약 있어?' 등 로컬 데이터 기반 조회

보존한 기능
- 기존 저장소 haru.assistant.v2.foundation 및 기존 키 마이그레이션
- 음성 인식, AI 일정 등록 및 확인, 수정/삭제, API 결제 및 사용량 링크
- Cloudflare Worker 엔드포인트와 OpenAI API 키 처리 방식 변경 없음

설치
1. 이 ZIP을 풀어 모든 파일을 GitHub Pages 테스트 저장소의 루트에 업로드/덮어쓰기.
2. GitHub Pages 반영을 기다린 뒤 iPhone Safari에서 새로고침.
3. 기존 데이터가 중요한 경우 업데이트 전에 '하루의 기록'에서 데이터 내보내기로 백업.
4. 기존 일정이 나의 일정 목록에 보이는지 먼저 확인.
5. 나의 일정 > 캘린더 보기 > 월 이동 및 날짜 선택 테스트.
6. 홈/오늘 브리핑 확인, '내일 일정 알려줘' 질문 테스트.
7. 음성 일정 등록 > 확인 > 목록 및 캘린더 반영 테스트.

주의
- 배포 및 실기기 테스트는 아직 수행하지 않았음. 파일의 문법 및 구조 검사만 수행.
- AI 일정 조회는 개인정보 보호를 위해 브라우저에 저장된 데이터를 로컬에서 읽음. 서버 AI에 전체 일정은 보내지 않음.
- '먼저 안내'는 앱을 열 때 홈 화면에 표시하는 방식이며, 앱 종료 상태에서 푸시 알림을 보내지는 않음.
- 음력/공휴일, 여러 날 연속 막대 표시, 진정한 다중 턴 AI 대화는 이번 시험판에 미포함. 후속 구현 및 검증 필요.
- 기존 2.2.1 앱에서 저장 키가 달라지거나 외부에서 데이터가 변경되면 일부 데이터가 보이지 않을 수 있음.
