하루 2.2.1 통합 개선판 (2026-11-17)

업로드: index.html, app.js, ai-bridge.js, voice-legacy.js, style.css, manifest.webmanifest (6개 파일).
GitHub haru-ai-test 저장소 루트에 업로드하고 커밋. 기존 데이터 JSON 백업 필수.

개선 내용
1. 음성 완료 후 인식 문장이 있으면 자동으로 AI 분석을 시작 (별도 전송 불필요).
2. 일정 확인창은 요약 카드 + 등록하기 한 번. 수정은 선택적으로 펼침.
3. 같은 날짜/시간에 일정이 있으면 등록 직전 중복 경고, 사용자가 결정.
4. 파란 포커스 테두리 제거, 자동 키보드 방지 유지.
5. 결제/사용량 링크는 새 창 또는 새 탭으로 열기. iOS Safari/PWA의 X 닫기 버튼은 브라우저가 제어하며 웹앱이 강제할 수 없음. 브라우저에서 원래 하루 탭으로 복귀.
6. 기존 저장 키와 AI Worker 엔드포인트 유지.

검증 절차
- 음성으로 '내일 오후 4시에 이비인후과 예약해 줘' -> 완료 -> 자동 분석 -> 요약 카드 -> 등록하기 -> 나의 일정 확인
- 같은 시간에 동일 일정 재등록 -> 중복 경고 확인
- 수정 펼치기 -> 시간 변경 후 등록
- 설정에서 결제 및 사용량 링크 열기, 원래 하루로 돌아오기
- 앱 종료/재실행 후 일정 유지 확인

주의: 실제 iPhone 동작과 브라우저의 X 버튼 노출은 배포 후 실기기 테스트가 필요함. API 키는 ZIP에 포함하지 않음.
