하루 3.0-N · AI 판단 유지 / 저장 후 홈 유지 시험판
기준: 하루 3.0-M
변경사항
1. 홈에서 AI 등록 확인창을 통해 저장하면 나의 일정 화면으로 강제 이동하지 않고 홈을 유지합니다.
2. 저장 확인 후 홈의 하루 답변을 실제 저장 완료 메시지로 교체합니다.
3. 음성 답변 설정이 켜져 있고 홈에서 저장했을 때 저장 완료 메시지를 음성으로 읽습니다(아이폰 정책에 따라 제한될 수 있음).
4. 저장 전에는 등록 완료라고 안내하지 않습니다.
5. AI 의도 판단 프롬프트 및 일정 파싱 구조, 기존 저장 키, 디자인은 유지합니다.
검증: JS 문법 검사, ZIP 구조 검사. 실제 아이폰 테스트 필요.
테스트: 홈에서 일정 말하기 → 하루의 제안 → 오케이 → 확인창에서 등록 → 홈 유지/답변 갱신/나의 일정에 저장 확인.
