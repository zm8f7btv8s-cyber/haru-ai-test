하루 2.3 안정화 개선판 / 아이폰 테스트용

원본: Haru_2.3_Integrated (기존 2.3 시험판).
포함: 홈 대화 진입, 채팅창 마이크, 음성 질문 후 침묵 감지 자동 전송, 음성 답변/다시 듣기/중지/설정, 일정 생성 의도 분기, 입력창 16px 및 모달 높이 대응.

설치: 기존 GitHub 소스 ZIP을 별도 백업하고, 이 ZIP의 내용물을 저장소 루트에 업로드하세요. Worker/API 키 변경 없음.
테스트: 1) 기존 일정 유지 2) 홈에서 대화 진입 3) 글 질문은 즉시 텍스트 답변 4) 마이크로 내일 일정 질문 후 잠시 멈춰 자동 전송과 음성 확인 5) 목요일 12시 화목회 식사 장소 마당 입력 후 확인창 6) 새 일정 열기/닫기/키보드 배율 7) 다시 듣기/중지/속도 8) 재실행 후 데이터 유지.

주의: 자동 음성 출력은 iOS의 사용자 동작/브라우저 정책에 의해 제한될 수 있습니다. 음성 인식 침묵 감지 1.7초는 시험값입니다. 실제 iPhone 기기 테스트 전에는 완성판으로 간주하지 마세요. 기존 일정 삭제, 저장소 초기화, API 키 파일 삽입 금지.
